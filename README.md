# Bojan Zdelar — Portfolio

Personal portfolio website of Bojan Zdelar, Serbian Olympic kayak sprint athlete specializing in K1 500m and K1 1000m.

**Live website:** [zdelar.com](https://zdelar.com)

## Features

- Athlete profile and career highlights
- International competition results archive
- Personal bests and championship achievements
- Partners and contact form
- Responsive design for desktop and mobile

## Built With

- HTML5
- CSS3
- JavaScript
- FormSubmit for contact form submissions
